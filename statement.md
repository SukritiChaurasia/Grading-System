Problem statement:

Managing grade manually was time consuming and can also have errors in calculations. 
This project will help to easily manage this records by taking some inputs of name, roll no, marks of different subjects and then will give the result of total marks, percentage, average and grade
The result will also be stored in a csv file and location of the file will also be visible.

Scope of the Project:

The scope of this project is to provide a simple Python-based system for calculating and storing students' academic results. The system can be used to:

Enter detail of the students and marks of five subjects.
Calculate total marks out of 500.
Calculate the student's percentage and average.
Give the grade based on the percentage calculated.
Display whether the student has passed or failed.
Save the result in a CSV file.
Display the location where the result file is saved.

The current project is designed for basic student result processing and does not include advanced features such as a graphical user interface, database connectivity, or online result management.

Target Users:

The main target users of this project are:

Students – to calculate and check their academic results.
Teachers – to quickly calculate and record students grades.
Schools/Colleges – for simple academic result processing.
Beginners learning Python – as a practical example of using Python modules, input handling, calculations, conditions, and CSV file handling.

High-Level Features:

The major features of the Student Grading System are:

Student Information Input – accepts the student's name and roll number.
Marks Input – accepts marks for English, Hindi, Physics, Maths, and Chemistry.
Total Marks Calculation – calculates the total marks obtained out of 500.
Percentage Calculation – calculates the student's percentage.
Average Calculation – calculates the average marks of the student by using statistics module of python.
Grade Assignment – assigns grades from A+ to F according to the percentage.
Pass/Fail Result – determines whether the student has passed or failed.
CSV File Storage – saves the student's result in students_results.csv.
File Location Display – displays the location of the generated CSV file.
